# Design and exactness contract

## Timing and horizon

States and observations are indexed 0/1. At each decision, reward depends on the current state and selected action. The state then transitions according to that action, and an observation is drawn conditional on the new state and action. A child policy is selected from the observed branch. Horizon H counts the number of actions/rewards remaining. Horizon zero has value zero and no action; no terminal reward is added. Discount one is valid because only finite horizons are supported.

For tree pi, let `alpha_pi[s]` be the exact expected discounted return starting from known state s. Conditional expectation over the first transition/observation gives the backup in README. The tree's value at belief b is linear: `b[0]*alpha_pi[0]+b[1]*alpha_pi[1]`. Finite horizon has finitely many trees, so its optimal value is a finite maximum of linear functions, hence piecewise linear and convex on the belief interval.

## Why envelope pruning preserves the next backup

Assume previous-layer vectors preserve the optimal continuation value at every belief. For a fixed root action and current belief, the expected future value is a sum across observations of observation probability times the optimal value at that observation's posterior. Each observation's continuation can be selected independently. Thus a maximizer exists using only previous retained envelope representatives. A zero-probability observation contributes zero, so any representative may be used for its branch. Enumerating every pair of retained continuations therefore preserves the root action's exact value at every belief, even though many original policy trees are not regenerated. Taking the maximum over root actions gives the exact next finite-horizon value. Induction starts at the zero vector.

This argument preserves values, not the set or number of optimal policy trees. Duplicate vectors retain one first-generated tree. A line touching the envelope only at a point can be discarded without changing the maximum, since a retained neighboring line has the same value at that point. Root-action values at the input belief are collected across all current candidates before pruning, independently of which root actions survive as representative envelope trees. They give every optimal root action at that belief. Returned `retained_maximizers` is not an all-tree tie set. Selecting the first retained maximum is a deterministic representative rule, not a global lexicographic-tree rule.

## Exact two-state upper hull

Write each vector as `y + x*b` with `x=alpha[0]-alpha[1]`, `y=alpha[1]`, and `b=P(state0)`. Deduplicate exact alpha pairs using insertion order. For equal slopes keep the largest intercept. Sort the remaining lines by increasing slope. Their upper-envelope slopes are monotone. A new line intersects the last hull line at `(old_intercept-new_intercept)/(new_slope-old_slope)`. If this crossing is no later than the last line's start, that last line has no positive-width envelope interval and is popped. Continue until starts strictly increase, then append. All comparisons/intersections are Fraction arithmetic, without a float tolerance.

The first start is negative infinity (internally None). Each piece ends at the next start, with the last ending at positive infinity. Clip those intervals to `[0,1]` and retain positive-width pieces. Their closed intervals share endpoints, cover the whole belief domain and preserve its maximum even when point-only supporting lines are removed. Output reports rational interval boundaries and values at both endpoints. Reassigned node IDs are the retained order by slope; children continue to reference dense IDs of the previous layer. The expanded selected tree follows those references without changing them.

Counts reconcile generated candidates into duplicate-vector removal, parallel dominance, hull removal, outside-domain removal and retained pieces. Initial horizon-zero vector is reported separately; `generated_candidates_total` sums actual subsequent backup candidates, not all original unpruned policy trees. Candidate preflight runs before candidate allocation/backup, enforces a requested 1..4096 per-layer cap and an aggregate 8192 cap, and returns no partial plan on refusal. It does not bound Fraction bit widths, time or RAM. Horizon/action/schema limits and denominator caps reduce scope but do not turn these counts into byte-cost guarantees.

## Bayesian update and the sensing control

Prediction is `pred[j]=sum_s b[s]*T[s][j]`. Observation z has unnormalized mass `pred[j]*O[j][z]`; their sum is its probability. Divide by this probability only when nonzero. Otherwise output posterior null. Summing the posterior mixtures over observations reconstructs the predicted distribution; tests check this identity and a nontrivial state-flip timing case.

The prescribed sensor has accuracy 9/10, cost 1/10, identity dynamics and equal prior. Each probe observation has probability 1/2 and yields posterior 9/10 for its indicated state. The best next exploit reward is `9/10-1/10=4/5`, giving total 7/10. An exploit action reveals nothing, so at the uniform belief its best two-step root value is zero. At belief b, two repeated exploits give lines `2*(1-2*b)` and `2*(2*b-1)`. The probe's observation-dependent policy has vector `[7/10,7/10]`. Their intersections are 13/40 and 27/40. Other probe continuations are below this envelope, as the exhaustive depth-two oracle verifies. This same-horizon control is not evidence of a sensor's value under different dynamics/rewards/horizons.

## Independent verification and scope

The production code uses alpha-vector backups and a sorted-line hull. The oracle builds complete observation trees and evaluates their returns by recursive state/trajectory expectation, without calling the production compiler/backup/hull. For 81 distinct declared model settings, all 27 depth-two trees give 2187 exact reference vectors. Each oracle set's pairwise rational line intersections partition `[0,1]`; testing every boundary and open-cell midpoint proves equality of the two piecewise-linear maxima throughout that interval for those models. Root-action values/ties are independently grouped before pruning. The tests reconstruct all returned layers and interval endpoint values.

A deeper fixture separately evaluates 2187 depth-three trees and compares solver boundaries plus 21 stated belief points with both tree enumeration and a separate recursive Bayesian belief planner. It is explicitly not an exhaustive depth-three crossing-cell audit. Analytic tests independently establish the demo's sensing value/thresholds, impossible observations, constant negative-return sums and horizon-zero semantics. Budget guards are unit-tested at their exact boundaries and mocked to verify first-layer refusal before any hull/backup completes. SVG metadata preserves the complete demo, with tests for exact geometry, regeneration and undisplayed-data tampering.

MIT finite-horizon POMDP lecture formulas are attributed in README. This implementation is a small supplied-model planning tool. It is not learned inference, a general-dimensional POMDP solver, a stochastic-model validation method, a real-world policy guarantee or an infinite-horizon convergence result. Rational arithmetic removes numerical rounding from these calculations, not uncertainty about the world.


## Fixed sequences and the feedback-gap certificate

For a fixed sequence `(a0,...,aH-1)`, start from zero terminal alpha and work backward with `alpha[s] = reward[a][s] + discount * sum_j T[a][s][j]*next_alpha[j]`. There is no observation sum because the continuation action is identical on every observation branch and each emission row sums to one. Enumerating the Cartesian product generates every possible fixed sequence in lexicographic action order, at most `3**4=81`. The full table retains every sequence and every input-belief tie. The existing exact upper-hull routine preserves its all-belief optimum, though envelope representatives alone do not preserve all sequence ties.

Any fixed sequence can be implemented by a contingent policy tree using the same next action under both observation children at every depth. Therefore the contingent feasible set includes every fixed sequence, with identical trajectory reward in the same model. Maximization proves `V_contingent(b) >= V_open_loop(b)` for every belief. The baseline is optimized over the entire smaller feasible set, not selected to look weak. The comparison does not give either policy hidden-state observations, different horizons, different dynamics or different costs.

Take the union of both exact envelopes' interval boundaries. Within each resulting open interval, one fixed alpha vector from each envelope attains its optimum, so their difference is affine. Evaluating its two endpoints proves nonnegativity on the entire interval. Continuity covers the boundaries. An affine function attains its interval maximum at an endpoint, or is constant. The algorithm takes the maximum across all exact knots, includes every maximizing point and every segment whose endpoints both attain that maximum, and merges touching closed components. This returns complete maximum-attaining intervals, not only example maximizers. The gap need not be convex because it is the difference of two convex functions.

Integrating each affine piece gives `(hi-lo)*(gap_lo+gap_hi)/2`; summing these exact rational trapezoids yields the uniform-belief integral. No samples, numerical quadrature or assumed real belief distribution enter this calculation. For the sensing fixture the gap is a triangle of base `7/20` and height `7/10`, so area is `49/400`. Its peak is at belief0=1/2. The declared uninformative-emission control has zero gap throughout `[0,1]`. These calculations compare feedback permissions within the supplied models. They do not isolate a real-world sensor mechanism or estimate learned performance.

Independent verification enumerates every full state path for each sequence and sums trajectory probabilities times discounted rewards, rather than calling the production backward recurrence. Across 81 declared depth-two models, 729 complete sequences and 2187 complete contingent trees independently define both oracle envelopes. All pairwise oracle alpha intersections, including dominated lines' intersections, partition the domain. Boundaries and each cell midpoint check the reported piecewise gap and witnesses; oracle trapezoids check the integral and oracle knots check the maximum. Horizon-four tests separately execute all 81 sequences under action-dependent stochastic dynamics and compare contingent values with independent Bayesian recursion at stated beliefs. Full-depth-four crossing-cell enumeration is not claimed. Flat maximum intervals, full sequence ties, zero/one horizon, single-action and zero-discount models are checked explicitly.

The original candidate caps govern the contingent solve. Comparison calls it first and propagates refusal, with no partial comparison or subsequent baseline enumeration. Fixed-sequence enumeration needs no additional user cap because the validated action/horizon scope already bounds its table to 81 entries. Neither count is a bound on Fraction bit sizes, operations, execution time or RAM.


## Forward occupancy evaluation of a supplied fixed policy tree

Parse the entire supplied tree before evaluating values. Every decision has exactly an action and two observation children; every leaf is null; both child subtrees must have equal height. Refusing a non-null node at depth four bounds every accepted tree to horizon at most four, 15 decisions and 16 terminal histories. This also stops cyclic Python inputs without following them indefinitely. Parsing constructs fresh tree objects, so an input subtree shared between children is not shared in the returned tree. A null root is the horizon-zero policy.

Let `mu[t,h,s]` denote joint probability of observation history h and current state s before the next action. Initialize it to the initial belief at the empty history. For the action a selected by that history, propagate `mu[t+1,h+z,j] = O[a][j][z] * sum_s mu[t,h,s]*T[a][s][j]`. Summing over j gives the branch's unconditional reach probability. Divide by the parent's reach probability for conditional branch probability; divide state mass by its own reach probability for conditional belief. A zero parent has no defined conditional branch probability, and a zero child has no defined conditional belief. They return null, while their unconditional masses remain exact zero. Both observation branches remain structurally present even when unreachable.

Current reward mass is `sum_s mu[t,h,s]*reward[a][s]`. Conditional reward divides this by nonzero reach; discounted mass multiplies by `discount**t`. Summing across decisions gives expected return by linearity. Each stochastic transition/emission row sums to one, so total history/state mass is conserved at each level; the implementation checks this exactly, including terminal histories. Horizon-zero/terminal reward is zero. Discount zero changes reward weights, not probability dynamics. A separate backward tree recursion computes policy alpha with the usual conditional expectation backup. Dotting it with the initial belief must equal the complete forward reward sum exactly.

## Exact regret of one fixed tree over all initial beliefs

Keep the supplied tree fixed as the initial belief varies. Its alpha is one linear function on the belief interval. The optimal finite-horizon value is the existing exact convex envelope. Subtracting the fixed alpha gives a convex, continuous, piecewise-affine regret function. Feasible-policy inclusion makes it nonnegative. On every exact optimal-envelope interval, subtract the two alpha vectors and evaluate both endpoints. Positive-width zero-regret pieces have both endpoint regrets zero; otherwise only an endpoint with zero regret contributes an isolated optimality point. Merge touching zero components to obtain the entire closed zero-regret set, including a tree optimal only at a point even if that tree was removed as an envelope representative.

The global maximum is attained at a domain endpoint because regret is convex. The implementation nevertheless checks all envelope knots and includes constant maximizing segments before merging complete maximizing components. This covers zero regret everywhere and two isolated endpoint maxima. The supplied probe tree's alpha is `(7/10,7/10)`, its zero-regret interval is `[13/40,27/40]`, and maximum regret is `13/10` at both certain-state beliefs. The fixed exploit0-twice tree has alpha `(2,-2)`, zero regret on `[27/40,1]` and maximum regret four at belief0=0. This is not the optimized fixed-sequence envelope, which may select a different sequence for each initial belief.

The independent trajectory oracle evaluates all 2187 declared depth-two tree/model pairs. A separate complete initial-state, state-path and observation-path enumerator computes joint prefix/state masses and reward contributions without the production forward or backward recurrences. It reconstructs every record for all 27 trees under action-dependent stochastic dynamics, plus all 31 records of a horizon-four selected tree. The regret oracle uses complete-tree alpha vectors and every pairwise crossing cell for all 27 sensing-model trees, checking values, witnesses, zero components, maxima and maximum components. An explicit third-action line optimal only at belief1/2 checks a discarded point-only tree. These are prescribed finite-model checks, not evidence of model calibration or safe real-world execution.
